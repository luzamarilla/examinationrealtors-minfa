1

物權基本概念

物權法定原則 §757
物權除依法律或習慣外，不得創設——只要條文沒明確寫過、習慣上也不曾承認的權利，都不能算是物權
跟債權完全不同：債權契約基於契約自由原則，就算民法找不到相同規範也承認是有效的「無名契約」；但物權沒有這回事，法條沒出現過就不被承認
習慣承認的物權例子：事實上處分權——違建因無法辦理第一次保存登記，本身不可能有所有權存在，但實務上承認新建人／使用權人對違建有「事實上處分權」，讓違建交易還是有規則可循
物權對世效（絕對權）
物權是絕對權，不是相對權——一旦取得這項物權，可以對全世界任何一個人主張
對比債之相對性：債權（相對權）只能在雙方當事人之間彼此主張；物權（絕對權／對世效）則是取得後對任何人都能主張，這是物權與債權最根本的差異
物權 vs 債權 比較總表
物權債權
定義直接支配特定物、享受其利益的權利得請求特定人為特定給付（作為或不作為）的權利
效力對象對世權（絕對權）——對任何人皆得主張對人權（相對權）——僅能對特定債務人主張
創設方式物權法定原則§757——僅依法律或習慣，不得任意創設契約自由原則——法無明文亦可成立有效的「無名契約」
公示原則須登記（不動產）或交付（動產）才生效力雙方意思表示合致即成立，不須公示
一物一權同一標的物上不能同時存在兩個內容相同的物權同一債務人可就同一給付，對多數債權人各別負同樣的債（不具排他性）
優先效力成立在先的物權優先於成立在後者，且物權優先於債權數個債權原則上平等、無先後優劣之分
追及效力標的物不論輾轉落入何人之手，物權人皆得追及行使權利僅能向特定債務人請求，不能對第三人主張
消滅時效原則上不因時效而消滅（所有權沒有消滅時效問題）原則上罹於消滅時效而使請求權消滅（一般 15 年）
簡單記法：物權「對世、法定、要公示」；債權「對人、自由、免公示」——後面①事實上處分權等例外規定，都是以這張表當對照基礎
不動產 vs 動產 物權得喪變更比較
比較項目不動產物權動產物權
生效要件書面登記（採公示原則）交付
為什麼這樣規定交易金額龐大，若無登記制度，容易發生無權處分、損害交易安全比不動產寬鬆許多，只要求交付即可
例外（登記／交付前已取得物權）繼承、強制執行、徵收、法院判決或其他非因法律行為無此類例外規定
例外之例外雖登記前已取得權利，但要處分該權利仍須先經登記—
「得」＝取得、「喪」＝喪失、「變」＝變化、「更」＝更動——這句口訣兩邊通用
動產交付方式細分 §761
交付方式內容
直接交付最常見、最基本，直接把動產交給受讓人
簡易交付 112測10受讓人已經先占有該動產，雙方讓與合意成立時直接生效，不用再實際交付一次
佔有改定讓與人（原所有人）與受讓人訂約，讓與人繼續佔有動產，受讓人取得間接佔有（兩方當事人，讓與人暫時留用）
指示交付動產由第三人佔有，讓與人將對第三人之返還請求權讓與受讓人，以代交付（三方當事人）
快速辨識：佔有改定是兩方（讓與人自己繼續占有）；指示交付是三方（東西在第三人手上）
佔有改定舉例：甲把機車賣給乙，但跟乙說這個月比賽要用、先讓他騎到月底，乙答應——所有權已經移轉給乙，機車仍在甲手上（甲直接占有／乙間接占有）
甲出賣人（讓與人）
→
對丙之返還請求權讓與
乙買受人（受讓人）
指示交付範例：甲把 A 車賣給乙，但 A 車實際上由丙占有中，甲無法直接交付 → 甲將自己對丙的返還請求權讓與給乙，乙之後直接向丙請求交還

所有權與物上返還請求權 §767107申論・111申論

所有權：得自由使用、收益、處分所有物之權利，並排除其他人之干涉（具排他性）
§767 I 三要件
要件內容
權利人物之所有人
對象無權利之人——判斷方式：對象有沒有受移轉交付、有沒有受所有權移轉登記等
行為對象佔有或侵奪所有物
⚠️ 考試最常挖的陷阱不是「對象有沒有佔有或侵奪」，而是「權利人到底是不是真正的所有人」——看題目時第一步永遠先確認這一點
§767 I 前段／中段／後段：三種請求權比較
返還請求權（前段）妨害除去請求權（中段）妨害防止請求權（後段）
遭無權佔有或侵奪時適用 對方沒有真的佔有，只是妨害所有權之行使（例如阻止進入、阻止使用） 對方連妨害行為都還沒真的做，只是有妨害之虞（有這個可能性存在）
中段、後段的樣態不要求「佔有中」這個要件——因為對方根本沒有真的佔有，看題目、用條文時要特別留意這點差異

所有權時效取得制度

跟民總的「消滅時效制度」是相反的方向：消滅時效是時效經過請求權罹於消滅；所有權時效取得則是符合條件、時間一到就取得物的所有權
非善意善意（無過失）共同要件
動產10 年5 年和平、公然、繼續佔有
不動產20 年10 年和平、公然、繼續佔有，且土地須為未經登記之不動產
⚠️ 不動產一旦已經登記給某人名下，就沒有時效取得制度的適用；縱使符合未登記＋佔有期間要件，不動產時效取得所取得的也只是「請求登記為所有人」的登記請求權，不是直接取得所有權——這是考試最容易忽略的細節

不動產所有權三大重要概念

① 袋地通行權
要件土地與公路無適宜之聯絡，致不能通常使用
效果土地所有人得通行周圍地以至公路
限制須於必要範圍內，且損害最少
A 地緊鄰公路，B 地在 A 地之後完全無法對外聯絡（袋地＝B地）→ B 地所有人得通行 A 地至公路，但不能任意挑最短路徑硬闖，須選損害最小的方式
② 區分所有權
定義：數人區分一建築物，各專有其一部分（如甲乙丙丁分別擁有大樓的一至四樓）
專有部分構造上得獨立使用、可單獨作為所有權標的（有獨立門戶出入即可）
共有部分專有部分以外之附屬物（頂樓、騎樓、花圃等）
⚠️ 專有部分與共有部分不可分開出售，兩者必須結合一起移轉
③ 越界建築
主觀要件非故意或重大過失，建築逾越地界
鄰地所有人及時異議得請求移去或變更房屋
鄰地所有人未及時異議不得請求移去或變更，但得請求支付償金
B 地所有人若沒有及時提出異議，等 A 地所有人蓋完房屋、開心使用之後，就不能再請求拆房子了，只能請求金錢補償

動產善意取得制度 §801§948109測驗・112測驗

要件 §801
①受讓人佔有動產沒有佔有，就沒有值得保護的權利
②受關於佔有規定之保護指下方 §948 的善意要件
③讓與人無移轉所有權之權利正因為讓與人是無權處分人，才有善意與否的問題
§948以動產所有權或其他物權之移轉或設定為目的而善意受讓該動產之佔有者，縱其讓與人無讓與之權利，其佔有人受法律之保護。但受讓人明知或因重大過失而不知讓與人無讓與權利者，不在此限
⚠️ 佔有改定的特殊限制：動產佔有之受讓若依§761 II（佔有改定）為之，須以受讓人受「現實交付」且交付時「善意」為限，才受善意取得保護——單純的佔有改定當下，受讓人其實還沒真正佔有這個物，權利還沒開始受保護，要等到真的受現實交付之後才算數

綜合實例題解析

甲為 A 地之所有人，適逢疫情來襲，甲決定出售 A 地給乙。甲乙約定於 112 年 3 月 1 日簽訂契約並辦理土地移轉登記。詎料，正當甲乙準備移轉 A 地所有權時，第三人丙趁 A 地無人看管，擅自佔用 A 地並於其上興建 B 屋。乙原先只是想等地價上漲後轉賣賺價差，並無使用 A 地之需求，完全沒注意到 A 地已遭丙佔用。
Q1｜乙若事後發現丙擅自占用 A 地，得如何主張其權利？
三要件檢視
①乙是 A 地所有權人（已辦妥移轉登記）— 具備；②丙是無權利之人 — 具備；③丙佔有中 — 具備
結論
三要件皆具備，符合§767 I 前段要件，乙得對丙主張民法第 767 條第一項前段物上返還請求權，請求返還 A 地
📝 答題技巧：標題直接下肯定結論（例如「乙得對丙主張民法第767條第一項前段物上返還請求權」），不要把題目原句抄一遍當標題、更不要用問號結尾——問號是問題不是答案。若對結論沒把握，可以先留一行空白，寫完論述後再回頭補標題
Q2｜若乙是 10 年後、20 年後才發現，情況是否不同？
先抓關鍵
看到「10 年」「20 年」要立刻聯想到不動產時效取得制度（善意10年／非善意20年）
檢視要件
時效取得制度僅適用於「未經登記」之不動產；本題 A 地在 112 年 3 月 1 日甲乙簽約時已辦理移轉登記，屬已登記不動產，不符合「未登記」要件，不需要再討論丙是否善意
結論
10 年後、20 年後結果都不會不同，丙仍是無權佔有人，乙仍得依§767 I前段請求返還。（假設性補充：縱使 A 地未登記，丙是趁機佔用、難謂善意，須以非善意 20 年時效計算；但縱使經過 20 年，不動產時效取得只是取得「請求登記為所有人」的權利，並非真正取得所有權，對乙而言丙仍是無權佔有人，結論依然不變）
甲另有一台豪華跑車 C 車，因疫情影響須出售維持家計，甲遂與丁簽訂 C 車買賣契約。正當甲準備將車交給丁之前，甲的乾兒子戊突然需要用 C 車當結婚禮車，甲與戊商量，希望先將 C 車借給戊，之後再移轉給丁。
Q3｜C 車所有權是否已經移轉？甲得如何移轉 C 車所有權給丁？
現實交付
不構成——甲並沒有直接把 C 車交給丁
佔有改定
可能構成——甲透過戊仍間接佔有 C 車（甲對戊有返還請求權），但題目沒說甲已把對戊的返還請求權讓與給丁，還不足以構成正式移轉
結論：所有權尚未移轉
甲得選擇：①等把 C 車從戊那裡取回後，用現實交付的方式交給丁；②改採指示交付——甲、丁約定，甲將對戊的返還請求權讓與給丁（三方關係：甲＝出賣人、丁＝買受人、戊＝占有 C 車的第三人）
承上，戊於借用 C 車過程中，因不知道甲已將 C 車出售給丁，將 C 車出售給善意的己，且已交付 C 車給己。事後丁前來詢問，才東窗事發。
Q4｜情況一：甲尚未對丁指示交付──丁得否請求己返還 C 車？
丁是否為所有人
甲從未把 C 車交付或指示交付給丁，實際上C 車所有人仍是甲，丁還不是所有人——§767 I前段第一個要件（權利人＝所有人）就不具備，丁不得對己主張物上返還請求權
補充論述
就算退一步討論，戊對 C 車所做的任何處分都是無權處分（戊本非有權利之人），依§118未經真正權利人承認前不生效力，戊交付給己的行為原則上是無權占有的基礎；但己是否受善意取得保護？己為善意受讓人、且受佔有規定保護、讓與人戊確實無移轉所有權之權利，符合§801/948善意取得要件，己仍能取得C車所有權
Q5｜情況二：假設甲已用指示交付方式把 C 車給了丁──結論是否不同？
丁是否為所有人
此時丁已受讓對戊之返還請求權，丁即為 C 車所有人，甲對 C 車已無權利可主張——§767要件①具備
己是否無權佔有
戊仍是無權處分人（戊從未取得所有權），戊交付給己的行為未經丁承認、不生效力，形式上己是無權占有
善意取得介入
己善意受讓占有＋受佔有規定保護＋讓與人戊無權利 → 符合§801/948，己仍善意取得 C 車所有權，丁不得請求返還
答題技巧
不論丁是否受指示交付（即是否為所有人），最終結論都一樣是「己善意取得、丁不能請求返還」；但完整論述仍應先帶§767 I前段逐一檢視三要件，再補§801/948善意取得，答案結構才完整，不能因為結論相同就跳過767的討論
Q6｜若將 C 車再出售給己的人是甲本人（不是戊），情況是否不同？丁得否對甲主張權利？
甲賣車給己
若甲未交付／未指示交付給丁，甲本身仍是C車所有人，甲是有權處分人，直接出售給己並不構成無權處分，己不需要靠善意取得就能合法取得所有權（佔有改定不受§948保護是因為丁未受現實交付，這裡不需討論，不影響甲己間的買賣有效性）；不論甲是否仍是所有人，己都能合法或善意取得C車所有權
丁得對甲主張什麼
一物二賣、可歸責於甲之給付不能：甲丁間買賣契約已成立，甲負有移轉C車之義務；甲明知與丁有契約仍故意將車另賣給己，屬可歸責於債務人之給付不能 → 丁得依債務不履行規定請求損害賠償或解除契約
其他可能主張
若甲已對丁完成指示交付（丁已取得所有權）而甲仍擅自出售給己，等同侵害丁之所有權，丁另可考慮依§184侵權行為請求損害賠償，或主張甲受領的價金屬不當得利請求返還
一物二賣不僅實務常見，考題中也是常見題型，務必熟悉「先定所有權歸屬 → 判斷是否無權處分 → 檢視善意取得 → 回頭看債務不履行」這條完整的答題脈絡

追及性標的物不論輾轉落入何人之手，物權人仍得追及行使權利 §867

公示原則與公信原則
公示原則不動產須登記 §758 I；動產須交付 §761
公信原則（保護善意第三人）不動產：§759-1 II＋土地法§43；動產：§801§948（即本堂善意取得制度）

物權優先性例題（一物二賣）
A 將甲屋賣給 B（成立債權），A 又將甲屋賣給 C 並完成移轉登記（取得物權）→ C（所有權）優先於 B（債權），物權效力優先於債權效力
B 無法向 C 主張任何物權上的權利，只能依債務不履行規定向 A 請求損害賠償§226或解除契約§256,260——邏輯跟本堂 IRAC 案例二「甲丁丙一物二賣」的答題脈絡完全一致
占有 ≠ 權利 §940
單純的「事實上管領力」（占有）本身不是權利，占有人是否受法律保護、能否對抗真正權利人，要另外檢視有無時效取得或善意取得等制度的適用，不能只憑「我現在占有著」就直接主張這是我的
