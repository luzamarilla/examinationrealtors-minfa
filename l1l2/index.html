意思表示瑕疵 ★★★★★

6-1｜真意保留 §86108測13・110測7・111測25
心裡想 A，卻故意說 B（講假話）——只有自己心裡有數（單方虛偽）
情形效果
相對人不知情（信以為真） 有效（不能事後反悔）
相對人明知表意人無真意 無效
白話例子
A 開玩笑說要送 B 名貴手錶，B 信以為真
→ A 不得以開玩笑拒絕履行 有效

但若 B 明知 A 在開玩笑
→ B 不能要求 A 履行 無效
6-2｜通謀虛偽意思表示 §87 ★★★★★110申論二25分・110測7・113測10
兩個人串通好，內心都是 A，卻故意做 B 給別人看（雙方都知道）
項目說明
要件① 雙方均明知無真意
要件② 雙方仍故意為之（缺一不可）
效果 無效
限制 不得對抗善意第三人
⚠️ 只有一方欠缺真意 → 不構成通謀虛偽，不適用§87
例1｜脫產行為
A 為脫產與 B 假裝買賣 → 雙方均明知無真意 → 無效
但若 B 已轉賣給不知情的 C → 不得以無效對抗 C
110年申論二（25分）｜同型考題實戰
甲為避免強制執行，與乙通謀虛偽買賣A地並完成移轉登記；乙死亡後子女丙丁辦妥繼承登記。買賣（債權行為）與移轉登記（物權行為）均無效，甲得依§767請求丙丁塗銷登記返還——因繼承登記非依法律行為之物權變動，不適用§759-1登記公信力，丙丁不算善意第三人
例2｜隱藏行為
A 對小三說是「買賣」，實質是「贈與」
→ 買賣契約 無效，贈與契約 有效

消滅時效 vs 除斥期間（完整版）★★★★★105・106・107・109測（110-114無資料）

比較項目 請求權（消滅時效） 形成權（除斥期間）
動作 跟對方要、拜託對方 一方說了算，直接變動法律關係
Keyword 請求（對方要動） 變動（關係直接改變）
期間 消滅時效 15 年（§125）
另有2年、5年短期時效		 除斥期間，通常較短
§93 詐欺脅迫：1年/10年
屆期效果 對方可以賴帳（抗辯權），權利不消滅 權利直接消滅，不得再主張
例子 請求損害賠償 解除契約、終止、撤銷
＋ 能否中斷：消滅時效可中斷、重新起算；除斥期間不可中斷，時間到就消滅
＋ 時效後自願履行：消滅時效完成後自願給付＝合法、不得要回；除斥期間屆滿後權利已不存在，無履行問題
＋ 法院角色：消滅時效要當事人自己主張，法院不得依職權審酌；除斥期間法院依職權主動調查是否屆滿

Issue

Rule
§125 消滅時效15年；時效後抗辯權
Apply

§767 物上返還請求權；釋字107、771號
Apply
情境A（A登記在丙名下）：
繼承回復請求權已逾（2/10年），改依§767
但甲以繼承身分行使→釋字771→有15年時效
20年 ＞ 15年 → 丁得主張時效抗辯

情境B（A已登記在甲名下）：
甲為登記所有權人→釋字107→無時效限制
結論
情境A → 甲無法請求（逾時效）
情境B → 甲仍可請求（無時效限制）
