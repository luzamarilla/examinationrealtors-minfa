🔥 最高頻（考過 3 年以上）（8項）
繼承配偶應繼分：跟各順序共同繼承，各拿多少？5年：108/109/111/112/113第一順序（直卑）：平均；第二（父母）、第三（兄弟姊妹）：1/2；第四（祖父母）：2/3；沒有其他繼承人：全部（112年誘答：配偶與父母1/3）
物權債權時效消滅後，抵押權人幾年內不實行，抵押權消滅？4年：105/106/110/113｜105申論時效完成後 5年（§880）；債權15年時效完成 → 再5年
總則一般消滅時效是幾年？已登記不動產的返還請求權有沒有時效？4年：105/106/107/113｜105・107申論一般 15年（§125）；已登記不動產返還、除去妨害請求權不適用消滅時效（釋字107／164）；未登記不動產、繼承人以繼承身分行使§767，仍是 15年（釋字771）（誘答：20年）
繼承遺囑能力：幾歲可以立遺囑？要不要法定代理人允許？4年：105/108/112/114滿 16歲；限制行為能力人立遺囑不用法定代理人允許（17歲未經允許仍有效）；未滿16歲、無行為能力人不得立
繼承拋棄繼承：多久內、向誰、用什麼方式？3年：105/110/112知悉得繼承之時起 3個月內，以書面向法院為之；溯及繼承開始時生效（誘答：戶政機關、言詞、被繼承人死亡時起算）
物權地上權人欠租到多少，土地所有人才可以終止？3年：108/109/114積欠地租達 2年之總額，先定相當期限催告，屆期不付才終止；有抵押權者要通知抵押權人（誘答：1年、「連續」2年、可逕行終止）
總則死亡宣告：一般失蹤、80歲以上、遭遇特別災難，各要滿多久？3年：110/112/114一般 7年；80歲以上 3年；特別災難終了滿 1年；撤銷死亡宣告向法院聲請（誘答：80歲5年、災難3個月、向地檢署）
總則完全、限制、無行為能力，年齡界線各是幾歲？3年：112/113/114完全：18歲以上；限制：7歲以上未滿18歲；無：未滿7歲（112年起成年改18歲，107、109年題目還是舊法20歲；受輔助宣告人仍有行為能力）
⭐⭐ 高頻（考過 2 年）（10項）
總則撤銷意思表示的除斥期間：錯誤、詐欺脅迫各多久？2年：108/114錯誤§90：意思表示後 1年；詐欺脅迫§93：發見詐欺或脅迫終止後 1年，但自意思表示後經過 10年 不得撤銷（114年誘答：錯誤2年）
親屬剩餘財產分配請求權的時效？差額怎麼分？2年：111/114知悉差額時起 2年／法定財產制關係消滅時起逾 5年；差額平均分配（各1/2）（誘答：「消滅時起2年」）
總則短期消滅時效：§126、§127 各是幾年？2年：106/112§126 5年：利息、租金、退職金等「1年或不到1年的定期給付」；§127 2年：旅店飲食費、運送費、租賃動產營業的租價、醫生律師報酬、承攬人報酬、商品代價等8款（「1年或不到1年」是適用範圍，不是時效）
債各不動產租賃期限超過多久要寫書面？沒寫會怎樣？2年：111/114逾 1年 應以字據訂立；沒寫 → 視為不定期限租賃（誘答：契約無效）
繼承遺產分割後，繼承人對被繼承人債務的連帶責任，多久免除？2年：106/110自遺產分割時起（清償期在分割後者，自清償期屆滿時起）經過 5年（§1171 II）（誘答：15年）
物權未定期限的地上權，存續逾幾年法院可以定期間或終止？2年：110/114逾 20年 或成立目的已不存在（§833-1）（誘答：30年、15年）
物權時效取得地上權要占有幾年？取得的是什麼？2年：109/113｜109申論準用時效取得：20年（善意無過失 10年），須以行使地上權之意思；取得的是請求登記為地上權人（以買受人身分占有，滿20年也不行）
物權共有物管理（§820）的多數決門檻？2年：106/111｜106申論共有人過半數＋應有部分過半數；或應有部分合計逾 2/3（人數不計）；簡易修繕、保存行為 → 各共有人單獨為之；分管契約同此門檻
繼承特留分比例？2年：109/113直系血親卑親屬、父母、配偶 ＝ 應繼分 1/2；兄弟姊妹、祖父母 ＝ 1/3（115.8.17修正刪兄弟姊妹，116.2.17才施行，考試仍用舊條文）
債總約定利率超過週年多少，超過部分無效？2年：109/112超過週年 16% → 超過部分無效（§205）（誘答：12%、20%（舊法））
⭐ 中頻（考過 1 年）（19項）
繼承口授遺囑什麼時候失效？1年：108遺囑人能依其他方式為遺囑之時起，經過 3個月
繼承債權人可以聲請法院命繼承人在多久內提出遺產清冊？1年：1063個月內（§1156-1）
總則因請求而中斷時效，多久內沒起訴就視為不中斷？1年：112請求後 6個月內不起訴 → 視為不中斷（§130）
物權遺失物：多久沒人認領歸拾得人？報酬上限？報酬請求權時效？1年：112通知或最後招領日起逾 6個月 → 拾得人取得；報酬不超過價值 1/10；報酬請求權 6個月（誘答：3/10）
總則暴利行為（§74）要怎麼撤銷？期限多久？1年：111須向法院聲請撤銷，法律行為後 1年內（是除斥期間，不是消滅時效）
親屬否認子女之訴要在多久內提起？1年：113夫妻之一方或子女，自知悉非婚生子女時起 2年內；子女未成年時知悉者，成年後2年內（§1063）
總則經確定判決後，時效重新起算幾年？1年：112原時效不滿5年者，重新起算的期間延長為 5年（§137 III）；原本15年的仍是15年
債總無權占有人使用房屋，相當於租金的不當得利，請求權時效？1年：111申論5年（實務類推§126）；房屋向占有人丙要，不是向擅自出租的乙要
物權質權人喪失質物占有，多久不請求返還，質權消滅？1年：1052年（§898）
物權地上權拋棄：有地租＋定期、有地租＋未定期，各要怎麼做？1年：109無地租 → 隨時拋棄；有地租＋定期 → 支付未到期 3年份地租；有地租＋未定期 → 1年前通知 或 支付未到期 1年份地租（誘答：無地租要1年前通知）
物權約定不分割共有物，最長可以約定幾年？1年：114一般不得逾 5年；不動產有管理約定不得逾 30年；超過縮短為5年／30年；有重大事由仍得隨時請求分割
物權抵押權優先受償的利息，限於多久內發生的？1年：110聲請強制執行前 5年內發生＋執行程序中發生的利息、遲延利息、1年或不及1年定期給付之違約金（§861 II）
繼承遺囑禁止遺產分割，效力最長幾年？1年：11010年（§1165 II）（誘答：20年）
物權典權：約定期限上限？絕賣條款要多長期限？幾年不回贖歸典權人？1年：106約定期限不得逾 30年；期限滿 15年 才可附絕賣條款；未定期限：出典後 30年 不回贖 → 典權人取得；定期：期滿後 2年 不回贖 → 取得
繼承各種遺囑要幾個見證人？1年：106公證、密封、口授：2人以上；代筆：3人以上；自書：不用（誘答：代筆2人）
親屬近親禁婚的親等範圍？1年：106直系血親、直系姻親：不論親等；旁系血親 6親等內；旁系姻親 5親等內且輩分不同（誘答：直系16親等）
親屬結婚年齡和方式？違反效果？1年：106男女未滿 18歲 不得結婚（違反→得撤銷）；書面＋2人以上證人簽名＋向戶政機關登記（違反→無效）（106年選項是舊法男17女15、公開儀式）
親屬共同財產制：離婚、一方死亡，共同財產怎麼分？1年：109離婚：取回訂約時財產，存續中取得的共同財產各得 半數；死亡：半數歸死亡者繼承人、半數歸生存配偶
債總法定利率多少？約定利率超過多少，債務人可以提前還本？1年：109未約定 → 週年 5%；超過週年 12% → 經 1年 後得隨時清償原本，但須 1個月前預告（誘答：6%）
📌 補充重點（考古題沒考過）（16項）
物權典權回贖要多久前通知？出典人出賣典物，典權人幾日內表示留買？回贖：6個月前通知；留買：收到通知後 10日內以書面表示
債各消費借貸未定返還期限，貸與人要定多久催告返還？1個月以上的相當期限（§478）；借用人則得隨時返還
物權地上權消滅後，工作物多久不取回就歸土地所有人？期滿請求補償要定多久？逾 1個月 不取回 → 歸土地所有人；期滿消滅前，定 1個月以上期間請求按建築物時價補償（拋棄、終止不適用）
債各欠租終止：房屋、建築基地各要欠到多少？房屋：欠租達 2個月租額；建築基地：達 2年租額；都要先定相當期限催告（土地法另規定押租金抵償後再欠2個月）
物權區分所有規約顯失公平，多久內可以訴請法院撤銷？規約成立後 3個月內（§799-1 III）
債各物之瑕疵擔保：解除權、減少價金請求權的期限？通知後 6個月 不行使，或自交付時起 5年 → 消滅；出賣人故意不告知 → 不受6個月限制，5年仍適用
債各承攬瑕疵：瑕疵發見期間、請求權時效各多久？發見期間：一般 1年、建築物或重大修繕 5年（故意不告知延為5年／10年）；請求權：瑕疵發見後 1年 不行使而消滅（§514）
債總侵權行為損害賠償請求權的時效？知有損害及賠償義務人時起 2年／自侵權行為時起 10年（§197）；時效完成後仍要依不當得利返還所受利益
繼承繼承回復請求權的時效？知悉被侵害時起 2年／繼承開始時起逾 10年；過了仍可依§767主張，但受 15年 限制（釋字771）
繼承繼承開始前幾年內受贈的財產，視為所得遺產？2年內（§1148-1）；目的是算遺產範圍（對外），跟§1173歸扣算應繼分（對內）不同
親屬判決離婚：生死不明、故意犯罪各要多久？生死不明已逾 3年；因故意犯罪，經判處有期徒刑逾 6個月確定（§1052）
債各未經公證的不動產租賃，期限多長就不適用買賣不破租賃？期限逾 5年 或未定期限（§425 II）
親屬為減少他方分配而處分婚後財產，幾年內的要追加計算？法定財產制關係消滅前 5年內（§1030-3）；履行道德義務的相當贈與除外
物權時效取得所有權：動產、未登記不動產各要占有幾年？動產 10年（善意無過失 5年）；未登記不動產 20年（善意無過失 10年）→ 取得「請求登記為所有人」
債各贈與法定撤銷：受贈人對哪些人故意侵害，贈與人可以撤銷？贈與人、其配偶、直系血親、三親等內旁系血親、二親等內姻親（§416）
總則監護宣告：哪些親屬可以聲請？本人、配偶、四親等內之親屬、最近1年有同居事實之其他親屬、檢察官、主管機關、社福機構、輔助人、意定監護受任人等

三、年：其他期限・存續期間（由短到長）
債各不動產租賃期限超過多久要寫書面？沒寫會怎樣？2年：111/114逾 1年 應以字據訂立；沒寫 → 視為不定期限租賃（誘答：契約無效）
物權地上權人欠租到多少，土地所有人才可以終止？3年：108/109/114積欠地租達 2年之總額，先定相當期限催告，屆期不付才終止；有抵押權者要通知抵押權人（誘答：1年、「連續」2年、可逕行終止）
物權質權人喪失質物占有，多久不請求返還，質權消滅？1年：1052年（§898）
繼承繼承開始前幾年內受贈的財產，視為所得遺產？2年內（§1148-1）；目的是算遺產範圍（對外），跟§1173歸扣算應繼分（對內）不同
物權地上權拋棄：有地租＋定期、有地租＋未定期，各要怎麼做？1年：109無地租 → 隨時拋棄；有地租＋定期 → 支付未到期 3年份地租；有地租＋未定期 → 1年前通知 或 支付未到期 1年份地租（誘答：無地租要1年前通知）
親屬判決離婚：生死不明、故意犯罪各要多久？生死不明已逾 3年；因故意犯罪，經判處有期徒刑逾 6個月確定（§1052）
債各未經公證的不動產租賃，期限多長就不適用買賣不破租賃？期限逾 5年 或未定期限（§425 II）
物權約定不分割共有物，最長可以約定幾年？1年：114一般不得逾 5年；不動產有管理約定不得逾 30年；超過縮短為5年／30年；有重大事由仍得隨時請求分割
物權抵押權優先受償的利息，限於多久內發生的？1年：110聲請強制執行前 5年內發生＋執行程序中發生的利息、遲延利息、1年或不及1年定期給付之違約金（§861 II）
親屬為減少他方分配而處分婚後財產，幾年內的要追加計算？法定財產制關係消滅前 5年內（§1030-3）；履行道德義務的相當贈與除外
繼承遺產分割後，繼承人對被繼承人債務的連帶責任，多久免除？2年：106/110自遺產分割時起（清償期在分割後者，自清償期屆滿時起）經過 5年（§1171 II）（誘答：15年）
總則死亡宣告：一般失蹤、80歲以上、遭遇特別災難，各要滿多久？3年：110/112/114一般 7年；80歲以上 3年；特別災難終了滿 1年；撤銷死亡宣告向法院聲請（誘答：80歲5年、災難3個月、向地檢署）
物權時效取得所有權：動產、未登記不動產各要占有幾年？動產 10年（善意無過失 5年）；未登記不動產 20年（善意無過失 10年）→ 取得「請求登記為所有人」
繼承遺囑禁止遺產分割，效力最長幾年？1年：11010年（§1165 II）（誘答：20年）
物權典權：約定期限上限？絕賣條款要多長期限？幾年不回贖歸典權人？1年：106約定期限不得逾 30年；期限滿 15年 才可附絕賣條款；未定期限：出典後 30年 不回贖 → 典權人取得；定期：期滿後 2年 不回贖 → 取得
物權未定期限的地上權，存續逾幾年法院可以定期間或終止？2年：110/114逾 20年 或成立目的已不存在（§833-1）（誘答：30年、15年）
物權時效取得地上權要占有幾年？取得的是什麼？2年：109/113｜109申論準用時效取得：20年（善意無過失 10年），須以行使地上權之意思；取得的是請求登記為地上權人（以買受人身分占有，滿20年也不行）
四、年齡・人數・親等（由小到大）
債各贈與法定撤銷：受贈人對哪些人故意侵害，贈與人可以撤銷？贈與人、其配偶、直系血親、三親等內旁系血親、二親等內姻親（§416）
繼承各種遺囑要幾個見證人？1年：106公證、密封、口授：2人以上；代筆：3人以上；自書：不用（誘答：代筆2人）
總則監護宣告：哪些親屬可以聲請？本人、配偶、四親等內之親屬、最近1年有同居事實之其他親屬、檢察官、主管機關、社福機構、輔助人、意定監護受任人等
親屬近親禁婚的親等範圍？1年：106直系血親、直系姻親：不論親等；旁系血親 6親等內；旁系姻親 5親等內且輩分不同（誘答：直系16親等）
總則完全、限制、無行為能力，年齡界線各是幾歲？3年：112/113/114完全：18歲以上；限制：7歲以上未滿18歲；無：未滿7歲（112年起成年改18歲，107、109年題目還是舊法20歲；受輔助宣告人仍有行為能力）
繼承遺囑能力：幾歲可以立遺囑？要不要法定代理人允許？4年：105/108/112/114滿 16歲；限制行為能力人立遺囑不用法定代理人允許（17歲未經允許仍有效）；未滿16歲、無行為能力人不得立
親屬結婚年齡和方式？違反效果？1年：106男女未滿 18歲 不得結婚（違反→得撤銷）；書面＋2人以上證人簽名＋向戶政機關登記（違反→無效）（106年選項是舊法男17女15、公開儀式）
五、比例・利率
繼承配偶應繼分：跟各順序共同繼承，各拿多少？5年：108/109/111/112/113第一順序（直卑）：平均；第二（父母）、第三（兄弟姊妹）：1/2；第四（祖父母）：2/3；沒有其他繼承人：全部（112年誘答：配偶與父母1/3）
物權共有物管理（§820）的多數決門檻？2年：106/111｜106申論共有人過半數＋應有部分過半數；或應有部分合計逾 2/3（人數不計）；簡易修繕、保存行為 → 各共有人單獨為之；分管契約同此門檻
親屬共同財產制：離婚、一方死亡，共同財產怎麼分？1年：109離婚：取回訂約時財產，存續中取得的共同財產各得 半數；死亡：半數歸死亡者繼承人、半數歸生存配偶
繼承特留分比例？2年：109/113直系血親卑親屬、父母、配偶 ＝ 應繼分 1/2；兄弟姊妹、祖父母 ＝ 1/3（115.8.17修正刪兄弟姊妹，116.2.17才施行，考試仍用舊條文）
債總法定利率多少？約定利率超過多少，債務人可以提前還本？1年：109未約定 → 週年 5%；超過週年 12% → 經 1年 後得隨時清償原本，但須 1個月前預告（誘答：6%）
債總約定利率超過週年多少，超過部分無效？2年：109/112超過週年 16% → 超過部分無效（§205）（誘答：12%、20%（舊法））
六、易混數字辨析
「2年／10年」vs「2年／5年」侵權§197、繼承回復§1146 ＝ 2年／10年；剩餘財產§1030-1 ＝ 2年／5年；詐欺脅迫撤銷§93 ＝ 1年／10年
「15年＋5年」不要混債權時效 15年（§125）完成後，抵押權再 5年不實行才消滅（§880）；兩個是不同的權利、不同的期間
「5年」家族§126定期給付、確定判決後重新起算、相當租金不當得利、§880抵押權、§861利息、不分割約定上限、§1030-3追加計算、§1171連帶責任免除、瑕疵擔保交付後、未公證租約逾5年
「1年」家族撤銷錯誤§90、詐欺脅迫§93、暴利§74（向法院）；不動產租賃逾1年要書面；承攬瑕疵請求權1年；地上權有租未定期1年前通知；特別災難失蹤1年
「3個月」家族拋棄繼承、口授遺囑失效、遺產清冊、區分所有規約撤銷
「6個月」家族瑕疵擔保通知後、請求後未起訴視為不中斷、遺失物認領與報酬請求權、典權回贖前通知、故意犯罪判刑逾6個月可訴請離婚
「1個月」家族利率逾12%提前還本預告、消費借貸催告、地上權工作物取回、地上權期滿請求補償
欠租門檻房屋租賃 2個月、建築基地租賃 2年、地上權 2年之總額——都要先催告
「2年」其他§127短期時效、質權喪失占有、典權期滿後不回贖、§1148-1生前贈與、否認子女之訴
20年／30年／10年地上權未定期逾 20年、時效取得 20年；典權期限上限 30年、未定期典權 30年、不動產管理約定不分割 30年；遺囑禁止遺產分割 10年
年齡7歲限制行為能力、16歲遺囑能力、18歲成年＋結婚、80歲失蹤3年可死亡宣告
比例1/2：特留分（直卑・父母・配偶）、配偶與第二三順序、剩餘財產差額、共同財產；1/3：特留分（兄弟姊妹・祖父母）；2/3：配偶與祖父母、共有管理人數不計門檻；1/10：遺失物報酬
利率5%法定 → 12%可提前還本 → 16%超過無效（誘答6%、20%）
親等近親禁婚旁系血親 6／旁系姻親 5；贈與撤銷旁系血親 3／姻親 2；監護聲請 4親等內
